Загружайте фотографии сюда (jpg, jpeg, png, webp, gif, avif).
После коммита сайт обновится сам примерно за минуту.

Порядок на сайте — по дате СЪЁМКИ фото (самые новые — наверху), она
берётся из EXIF-метаданных самого файла (их записывает камера или
телефон), а не из даты загрузки на GitHub. Если у фото нет EXIF-даты
(например, это скриншот или графика без метаданных) — сайт возьмёт
дату коммита, в котором файл был добавлен.

Номер под каждым фото — это тоже порядковый номер по дате съёмки,
присваивается и пересчитывается автоматически при каждой публикации.

Фото на сайте автоматически сжимаются (уменьшаются и пережимаются
в JPEG), чтобы страница быстро грузилась — отдельно сжимать перед
загрузкой не нужно.

Файлы HEIC (айфон) браузеры не показывают — сначала сохраните их как JPG.
Важно: при конвертации HEIC → JPG используйте программу, которая
сохраняет EXIF-данные (дату съёмки), иначе фото попадёт в ленту по
дате загрузки, а не по дате съёмки.
