# Скуратовские котики

Одностраничный сайт-галерея фотографий кофейных стаканчиков. Стиль: чёрный лофт (кирпич, лампа Эдисона) и крафтовая бумага, как на стаканчиках. Крупные фото, на телефоне — вертикальная лента «одно фото на экран».
Посетители могут только смотреть и приближать фото (тап по фото → двойной тап / щипок / колесо мыши).

## Как выложить на GitHub Pages

1. Создайте на GitHub **публичный** репозиторий (для бесплатного аккаунта Pages работает только с публичными).
2. Загрузите в него все файлы этого проекта (в корень, ветка `main`), включая скрытую папку `.github`.
3. Откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
4. Во вкладке **Actions** дождитесь зелёной галочки. Адрес сайта появится в **Settings → Pages**
   (обычно `https://ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`).

## Как добавлять фото (администратор)

Администратор — любой, у кого есть право записи в репозиторий.

1. Откройте папку `photos` в репозитории на GitHub.
2. **Add file → Upload files**, перетащите фото, нажмите **Commit changes**.
3. Через ~1 минуту фото появятся на сайте. Список фото собирается автоматически.

Удалить фото — открыть файл на GitHub и нажать значок корзины.

Советы:
- Порядок в ленте — по имени файла (`01.jpg`, `02.jpg`, …). Чтобы новые были сверху, называйте их с убывающими номерами.
- Оптимальный размер — по длинной стороне 1600–2400 px, до 1–2 МБ на файл. Так сайт быстро грузится.
- Формат HEIC (айфон) браузеры не открывают — конвертируйте в JPG.

## Просмотр на своём компьютере

```bash
python3 -c "import os,json;print(json.dumps(sorted(f for f in os.listdir('photos') if f.lower().endswith(('.jpg','.jpeg','.png','.webp','.gif','.avif'))),ensure_ascii=False))" > photos.json
python3 -m http.server 8000
```
Откройте http://localhost:8000. Файл `photos.json` нужен только локально: на GitHub он создаётся автоматически.

## Важно знать

- Сайт статический, поэтому загрузка фото идёт через репозиторий, а не через форму на странице.
- Фото публичны. Сайт не даёт кнопок скачивания и редактирования, но полностью защитить снимки от сохранения
  (скриншот, «сохранить как») в браузере нельзя.
